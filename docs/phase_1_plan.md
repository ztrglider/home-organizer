# Phase 1 Plan

The first milestone focuses on solidifying the foundational Room Chore Picker integration so it is reliable and configurable enough to be useful in a real household.

- [x] Set up the base custom integration with a weekly shuffle service and sensor.
- [x] Add configuration options so households can limit the shuffle to a curated list of areas and optionally exclude sensitive rooms.
- [x] Document the new configuration options and expected behavior for advanced users.
- [ ] Add unit coverage for the selection logic so regressions are caught early.
- [ ] Evaluate logging and diagnostics needs for visibility into upcoming shuffles.
